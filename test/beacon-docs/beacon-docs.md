# README

Beacon turns raw data from your tools into scheduled reports and live dashboards. Connect a source, pick the fields you care about, and Beacon keeps the numbers fresh without spreadsheets or SQL.

## What you can do with Beacon

* Connect Google Sheets, PostgreSQL, and Stripe as data sources.
* Build dashboards from connected sources.
* Send scheduled reports to email and Slack.
* Trigger webhooks when a metric crosses a threshold.
* Run Beacon in the cloud or self-host it with Docker.

## Where to start

New to Beacon? Follow the [Quickstart](/broken/pages/5f4bb6f7b57ddc72abf1a95db0b3fdd034e9be23). Migrating a team? Read [User roles and permissions](/broken/pages/783e93929ea94422b5132b212376955b215e3c60) first, then connect your sources.
