# quickstart

This guide takes you from a new account to your first dashboard in about ten minutes.

{% stepper %}
{% step %}
## Create a workspace

After signing up, Beacon asks you to name a workspace. A workspace holds your sources, dashboards, and team members. You can rename it later from **Settings → General**.
{% endstep %}

{% step %}
## Connect a source

Open **Sources → Add source** and choose a connector. For a quick test, connect a Google Sheet that has a header row — see [Connect Google Sheets](/broken/pages/34cf94563b2e5beb8c1d1a3c450daef259d225a8).
{% endstep %}

{% step %}
## Build a dashboard

Go to **Dashboards → New dashboard**, click **Add tile**, and choose the source and the field you want to chart. Beacon supports line, bar, number, and table tiles.
{% endstep %}

{% step %}
## Share it

Click **Share** in the top-right corner. You can invite teammates by email or copy a read-only link. Read-only links expire after 30 days.
{% endstep %}
{% endstepper %}
