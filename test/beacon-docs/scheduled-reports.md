# scheduled reports

A scheduled report sends a snapshot of a dashboard to email or Slack on a recurring schedule.

## Create a report

{% stepper %}
{% step %}
### Open the dashboard

Open the dashboard you want to send.
{% endstep %}

{% step %}
### Schedule the report

Click **Schedule** in the top-right corner.
{% endstep %}

{% step %}
### Choose a frequency

Choose the frequency: daily, weekly, or monthly. Times use the workspace time zone.
{% endstep %}

{% step %}
### Add recipients

Add recipients. You can enter email addresses or pick a Slack channel if Slack is connected.
{% endstep %}

{% step %}
### Save

Click **Save**.
{% endstep %}
{% endstepper %}

## Format

Email reports include a PNG snapshot of every tile and a link to the live dashboard. Slack reports include the same snapshot as an image attachment.

## Pausing a report

Open **Dashboards → Schedules**, find the report, and toggle it off. Paused reports keep their settings.
