# Movo — landing page

Landing page for the Movo app design concept (Figma: Parkit / `site`), built with Next.js.

## Develop

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this repository in Vercel and set **Root Directory** to `movo`. Framework preset: Next.js (auto-detected).

## Notes

- Layouts follow the two Figma frames: `14'` (≥900px) and `16'+` (≥1728px), with a stacked layout below 900px.
- The logo reveal animation comes from the Figma motion timeline and plays once on load.
- `public/assets/v1-video.mp4` is placeholder footage from danielamuntyan.com matching the Version 1 still.
- The TestFlight / Figma / browser links are placeholders (`#`) in `app/page.tsx`.
